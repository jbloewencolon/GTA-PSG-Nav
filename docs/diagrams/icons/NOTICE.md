# Logo icons

The SVG files in this folder come from [Simple Icons](https://simpleicons.org) 16.38.1 (npm package `simple-icons`), which releases its icon data under CC0 1.0.

The logos are trademarks of their owners: Python (Python Software Foundation), GitHub and GitHub Actions (GitHub, Inc.), HTML5 (W3C), CSS and JavaScript. They are used here only to identify the technologies this project uses, in each brand's colour. Follow each owner's brand guidelines before reusing them elsewhere.

Microsoft product logos (Azure, Power BI) are not included: Simple Icons does not carry them. Diagrams use generic pictures with the product name instead. Microsoft publishes official Azure architecture icons for use in architecture diagrams, under its own terms.
